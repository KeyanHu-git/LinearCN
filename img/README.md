# Image assets

本目录只保存项目品牌资源和扩展清单直接引用的图标。

| 文件 | 功能 |
| --- | --- |
| `linearcn-icon.png` | 项目主图，README 和后续尺寸生成的来源 |
| `favicon-16x16.png` | 浏览器工具栏小尺寸图标 |
| `favicon-48x48.png` | 扩展管理页图标 |
| `favicon-128x128.png` | 商店、安装页和高分辨率扩展图标 |

三个 favicon 必须由同一主图等比缩放生成，不单独绘制或加入平台专用变体。替换主图后，应在 16、48、128 像素下分别检查轮廓和对比度。
