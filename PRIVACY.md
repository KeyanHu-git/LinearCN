# Privacy policy

LinearCN performs local interface-text replacement on Linear pages.

## Data collection

The extension does not collect, store, sell, or transmit personal or sensitive data.

## Network access

The extension does not make network requests. It does not use analytics, telemetry, advertisements, remote configuration, or remotely hosted executable code.

## Page access

The extension runs only on `linear.app` and its subdomains. It examines DOM text and selected accessibility attributes to match reviewed interface strings. It deliberately skips editable fields, code blocks, issue links, project links, and other protected user-content areas.

## Authentication

The extension does not read passwords, passkeys, cookies, OAuth tokens, API keys, or session storage.

## Changes

Any future behavior that changes this policy must be documented before release and reflected in browser-store disclosures.
